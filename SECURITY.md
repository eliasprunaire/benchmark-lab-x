# Sécurité

## Signaler une vulnérabilité

Ne publiez pas une vulnérabilité dans une Issue, une pull request ou une Discussion. Utilisez **Report a vulnerability** dans l’onglet [Security](https://github.com/eliasprunaire/benchmark-lab-x/security) pour envoyer un rapport privé aux mainteneurs.

Indiquez si possible :

- le composant et le commit concernés ;
- l’impact observé ou probable ;
- les conditions nécessaires à l’exploitation ;
- une reproduction minimale sans donnée privée ;
- une correction ou une mesure de réduction du risque, si vous en connaissez une.

N’incluez jamais de clé, jeton, donnée personnelle, sortie privée de campagne ou accès réel à une infrastructure. Les mainteneurs accuseront réception dans le canal privé GitHub et coordonneront l’analyse, la correction et la divulgation éventuelle.

## Problèmes non sensibles

Une erreur fonctionnelle sans implication de sécurité peut être signalée dans les [Issues](https://github.com/eliasprunaire/benchmark-lab-x/issues).
